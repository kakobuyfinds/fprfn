How to use the HipoBuy spreadsheet

  1. Find the exact listing. Search by item ID or category. Open the product page and match the color, size and variant you want.
  2. Compare measurements and photos. Measure a similar item you own. For shoes, check the seller’s sizing instructions and insole measurements where available. If warehouse quality-control photos are available, match them to the selected variant.
  3. Estimate the total. Start with the current variant price and add domestic delivery, any service fee, international shipping and applicable import charges. Check whether the shipping quote uses actual weight or volumetric weight.

Frequently asked questions

What is a HipoBuy spreadsheet?

It is a shopping directory for comparing product listings. This independent guide uses a sample of HipobuyFind listings, with item IDs, categories and reference prices.

Does the displayed price include shipping?

The table shows the listed item price in Chinese yuan. Check each listing’s current price and get a shipping quote for your destination before ordering.

How do I find the item again if its title changes?

Keep the HipobuyFind product URL and its item ID. If the listing disappears, use the category links to look for alternatives and check their seller details separately.
